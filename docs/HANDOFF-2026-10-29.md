**Decision the owner has not answered (PR #27):** the ADR says `Home`'s methods and callers become async. I kept the old synchronous names on `Home<FileStore>` (they run the async ones, which a `FileStore` finishes without waiting) because about 700 call sites would change and the instruction was that `app` and `desktop` compile unchanged. So there are two spellings (`load_contacts()` and `load_contacts_async()`) until step 5. The sync wrappers exist only for `Home<FileStore>`.

Facts worth knowing before step 3:
- `SystemTime::now()` **compiles** for wasm and **panics** when it runs ("time not implemented on this platform"). The CI job can only catch the runtime panic through a test that runs. `core/tests/wasm_envelope.rs` has one test that runs and one `#[ignore]`d test that shows the panic (run with `-- --include-ignored`).
- `cli` enables `tokio` features `net` and `rt-multi-thread`, which do not build for wasm; the new crate must not. `ops.rs:750` uses `tokio::time::timeout` directly.
- `Relay::connect` calls `dial` in `transport.rs` (native). Shared code needs the `Connector` trait.
- `direct.rs` stays native (TCP, UDP, hostname lookup). `ops.rs` calls it at lines 230-233 and 518.
- To run the wasm test locally: `CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUNNER=wasm-bindgen-test-runner cargo test -p spike-core --target wasm32-unknown-unknown --test wasm_envelope` (`wasm-bindgen-cli` must match the `wasm-bindgen` version in `Cargo.lock`, 0.2.129).

## 3. Browser identity draft (review done, nothing changed)

The draft is `docs/spike-adr-draft-browser-identity.md` in the private repo `akarapolb/CenterWork`. I reviewed it against ADRs 0008, 0010, 0021, 0024 and 0030; the owner will edit it. The findings:

- Works as written: a stranger accepted as a contact can be added to a small group right after (two quick local actions: `groups::add` takes a contact by name); the request flow needs no change; Argon2 parameters travel in the plain `vault.json` header, so a browser can pick its own; nothing needs a wire, relay or crypto change.
- Wrong or needs a change: "removal re-keys as ADR 0024 requires" (small groups have no re-keying: a removal is a new signed state, the removed person just stops being a recipient and keeps what they received; only large MLS groups really re-key); the group has no "owner" (the creator is only the first admin, admins are equal, so any promoted admin can remove the owner); small groups are capped at 20 people (large groups reach 500 but are experimental and `spike-mls` was only compiled for wasm, never run); held request text is cut at 4096 bytes (`MAX_HELD_BYTES`, so an invitation carrying the owner's whole card can be truncated and fail its signature); 50 pending requests per owner, extras are dropped silently; no app shows "asks to join <file>, invited by <member>" and the local API has no calls for requests or groups; invitation signing and checking is new code; no minimum Argon2 parameters are enforced.
- Could not tell: whether a browser identity's key packages can join a large group while closed; whether Argon2 at 64 MiB works on a phone browser.

## 6. How to build and check (everything below worked this session)

```bash
# Rust: format, lints, tests (452 pass on Windows)
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --no-fail-fast
# desktop (its own workspace)
CARGO_TARGET_DIR=D:/Android/tgt-desktop cargo test --manifest-path desktop/src-tauri/Cargo.toml
# desktop drivers (two real windows and a real relay)

node desktop/drive_apps.mjs     # also: drive_backup, drive_restart, drive_share, drive_large, drive_call
# Android APK
export ANDROID_NDK_HOME=D:/Android/sdk/ndk/27.2.12479018 ANDROID_HOME=D:/Android/sdk JAVA_HOME=D:/Android/jdk
bash android/build-native.sh --release && (cd android && ./gradlew assembleDebug)
ANDROID_SERIAL=emulator-5554 node android/drive_mobile.mjs   # also: drive_apps, drive_link_new, drive_backup
# the demo script CI runs
bash scripts/demo.sh
```

Gotchas: this checkout uses CRLF (`core.autocrlf=true`), so a test that reads `Cargo.lock` must tolerate it (fixed in `mls/tests/pin.rs`). In Git Bash, set `MSYS2_ARG_CONV_EXCL="*"` before `git show origin/branch:path`. A first Android build of the Rust library takes about 2 minutes, a first desktop build about 10.
