Interactive demo · Spike Connect · multi-device design

Two people, several devices, one relay that can't read anything

Send messages from any device, take devices offline, add a new one, edit and delete, switch the relay off, and try attacks. Everything here follows the proposed design in multi-device-design.html.

Simulation.No real encryption or network runs in this page. "Ciphertext" is random bytes, made per device to show the relay sees something different for each. The real prototype (CLI and relay) is in the repository; multi-device itself is still only designed.
